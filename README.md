# Fairness Analysis of Predictive Models using Stanford Open Policing Data (Wichita, Kansas)

## Overview
This project evaluates the performance and fairness of a predictive model using real-world policing data from the Stanford Open Policing Project, focusing on traffic stop outcomes in Wichita, Kansas.

Rather than only optimizing predictive accuracy, this project investigates:
- Model reliability under class imbalance  
- Impact of threshold selection  
- Presence of demographic disparities  
- Real-world implications of model deployment  

---

## Dataset
This project uses the Stanford Open Policing Project dataset, specifically:
- Traffic stop records from Wichita, Kansas
- Includes features such as:
  - Violation severity  
  - Race  
  - Age  
  - Time of day  
  - Location  

---

## Problem Statement
Predictive models in high-stakes domains like policing can:
- Show high accuracy while masking poor performance  
- Introduce or reinforce bias  
- Lead to unfair outcomes if deployed without proper evaluation  

This project answers:    
How reliable and fair is the model when evaluated beyond traditional metrics?
